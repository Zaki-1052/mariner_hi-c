     Superenhancer Hub Analysis — Implementation Plan

     Context

     The CTEA/Dixon meeting identified superenhancer (SE) hubs as a key analysis
      target: do differential stripes overlap SE domains, and do genes within SE
      hubs show correlated changes in enhancer contact frequency and H3K27ac? No
      SE-related analysis script exists yet in the repo. All input data (SE
     BEDs, DEG Excel files, annotated stripe BEDPEs, K27ac DiffBind results) is
     ready. This analysis addresses TODO Section 1 (subsections 1a, 1b, 1c).

     ---
     Architecture

     4 new files, all in R, following existing script conventions:

     loops/scripts/
       utils/
         se_utils.R                    # NEW — shared SE/DEG/bedtools helpers
       se_deg_proximity.R              # NEW — 1a: SE-DEG proximity analysis
       se_stripe_overlap.R             # NEW — 1b: differential stripes x SEs
       se_hub_classification.R         # NEW — 1c: SE hub gene coordination

     loops/output/superenhancer_analysis/
       1a_se_deg_proximity/{late,early}/
       1b_se_stripe_overlap/{late,early}/
       1c_se_hub_genes/{late,early}/

     ---
     Step 1: Create se_utils.R (shared utility)

     Path: loops/scripts/utils/se_utils.R

     Provides reusable functions sourced by all three analysis scripts:

     Function: load_se_bed(se_file, label)
     Purpose: Read headerless 4-col SE BED → GRanges with $se_name, $se_source
     ────────────────────────────────────────
     Function: load_all_ses(p60_file, encode_file)
     Purpose: Load + merge both SE sets, retaining source label
     ────────────────────────────────────────
     Function: load_rna_for_se(rna_file)
     Purpose: Read DEG Excel → return list(degs, all_genes) with full gene table
      for
       invariant selection. Uses same ensembl_gene_id = gene symbol gotcha as
       load_rnaseq_degs() in deg_loop_anchor_violin.R:L93-100
     ────────────────────────────────────────
     Function: select_invariant_genes(degs, all_genes, n_per_deg=3)
     Purpose: Match invariant genes by baseMean quintile x chromosome, 3:1 ratio
     ────────────────────────────────────────
     Function: get_gene_coordinates(gene_symbols)
     Purpose: Map symbols → chr/tss via TxDb.Mmusculus.UCSC.mm10.knownGene +
       org.Mm.eg.db
     ────────────────────────────────────────
     Function: bedtools_intersect_gr(query_gr, subject_gr)
     Purpose: Write temp BEDs, run /opt/homebrew/bin/bedtools intersect -wa -wb,

       return tibble of hits
     ────────────────────────────────────────
     Function: load_k27ac_diffbind(diffbind_file)
     Purpose: Read K27ac DiffBind TSV → GRanges with $fold, $fdr
     ────────────────────────────────────────
     Function: classify_k27ac_change(peaks_gr, diffbind_gr)
     Purpose: Classify each peak as gained/lost/stable K27ac based on
     overlapping
       DiffBind result

     Key reuse: Pattern from deg_loop_anchor_violin.R (DEG loading, GREAT-style
     domains, gene coordinate lookup). Multi-format output via existing
     loops/scripts/utils/multi_format_output.R.

     ---
     Step 2: Create se_deg_proximity.R (1a)

     Path: loops/scripts/se_deg_proximity.R
     Usage: Rscript loops/scripts/se_deg_proximity.R --timepoint late|early|both

     Logic

     1. Load DEGs + invariants — load_rna_for_se() → DEGs (padj<0.05, |lfc|>0.3)
      + all genes. get_gene_coordinates() adds chr/tss. select_invariant_genes()
      picks 3 matched invariants per DEG (baseMean quintile x chromosome).
     2. Load SE + enhancer references — P60 SEs (1,046), ENCODE SEs (52),
     ChromHMM active enhancers (28,110 from
     peaks/251230-Challana-EmissionState12-activeenhancer.bed), K27ac ChIP peaks
      (peaks/beds/H3K27acCerebellum{Late2,Early2}.bed). Both enhancer references
      run as separate comparison arms.
     3. Build 2 Mb windows — GRanges centered on each gene's TSS ± 2 Mb.
     findOverlaps() against SE GRanges and each enhancer reference.
     4. K27ac sub-classification — Load DiffBind K27ac
     (peaks/diffbind/K27ac_diffbind_results_summit_appended_ap.txt).
     classify_k27ac_change() on SEs → label each SE as gained/lost/stable K27ac.
     5. Statistics — Wilcoxon: DEG_up vs invariant, DEG_down vs invariant for
     n_SEs_within_2Mb. Fisher exact: concordance of DEG direction with K27ac
     change direction at proximal SEs.
     6. Figures — (i) Violin: n_SEs per gene class. (ii) Stacked bar: K27ac
     subclass proportions. (iii) Scatter: n_SEs vs gene log2FC with Spearman
     rho.
     7. APA prep (HPC-only) — Write gene-SE pairs as BEDPE for later
     pullHicMatrices() on Expanse. Outputs apa_inputs/{tp}_deg_se_pairs.bedpe +
     launcher script stub.

     Input files

     - peaks/Superenhancers_P60.bed, peaks/Superenhancers_encode.bed
     - tads/adult_timepoint_rna-seq-BAP1_WT_KO_v2_Results.xlsx (late)
     - tads/young_timepoint_rna-seq-Bap1Math1paired_ctrl_mut_Results.xlsx
     (early)
     - peaks/diffbind/K27ac_diffbind_results_summit_appended_ap.txt
     - peaks/251230-Challana-EmissionState12-activeenhancer.bed
     - peaks/beds/H3K27acCerebellumLate2.bed / H3K27acCerebellumEarly2.bed

     ---
     Step 3: Create se_stripe_overlap.R (1b)

     Path: loops/scripts/se_stripe_overlap.R
     Usage: Rscript loops/scripts/se_stripe_overlap.R --timepoint 
     late|early|both --stripe-set allsig|highconf|concordant

     Logic

     1. Load stripes — Read annotated BEDPE (32-col, header). Build anchor
     GRanges from chr1/x1/x2. Keep direction, logFC, FDR, h3k27ac columns.
     2. Load SEs — P60 and ENCODE sets loaded separately for comparison.
     3. Overlap — bedtools_intersect_gr(): stripe anchors x P60 SEs, stripe
     anchors x ENCODE SEs. Add boolean columns se_P60_overlap,
     se_ENCODE_overlap.
     4. Contingency tests — Fisher exact on 2x2 (direction x SE overlap) per SE
     set. Tests: are gained stripes enriched for SE overlap?
     5. K27ac concordance — For SE-overlapping stripes: classify K27ac change at
      the overlapping SE. Test whether gained stripes at SEs have gained K27ac
     (and vice versa). Chi-squared for concordance.
     6. P60 vs ENCODE comparison — Count stripes overlapping each SE set by
     direction; Venn-style breakdown.
     7. Figures — (i) Bar: gained/lost stripe counts by SE overlap. (ii) Mosaic:
      direction x overlap proportion. (iii) Violin: logFC of stripes by SE
     overlap status. (iv) Concordance stacked bar.

     Stripe sets by timepoint

     - Late (250402): allsig (1,404 stripes), highconf (1,015)
     - Early (250831): allsig (61), concordant (134) — both run separately
     - Default: allsig for late, concordant for early; --stripe-set flag
     overrides

     Input files

     - stripes/stripenn/outputs/250402/250402_stripes_{allsig,highconf}.bedpe
     - stripes/stripenn/outputs/250831/250831_stripes_{allsig,concordant}.bedpe
     - peaks/Superenhancers_P60.bed, peaks/Superenhancers_encode.bed
     - peaks/diffbind/K27ac_diffbind_results_summit_appended_ap.txt

     ---
     Step 4: Create se_hub_classification.R (1c)

     Path: loops/scripts/se_hub_classification.R
     Usage: Rscript loops/scripts/se_hub_classification.R --timepoint 
     late|early|both

     SE Hub Definition

     A SE-hub stripe = stripe whose anchor region (chr1:x1-x2) overlaps at least
      one SE. The stripe body contacts all genes in body_genes — these are the
     hub genes. The biological model: the SE at the anchor modifies multiple
     promoters along the stripe.

     Logic

     1. Load stripes — Use allsig BEDPE (already has body_genes,
     body_gene_count). Build anchor GRanges, overlap with SEs. Mark se_hub_P60,
     se_hub_ENCODE, se_hub_any.
     2. Extract hub genes — Split body_genes (comma-separated) into individual
     rows. Filter to SE-hub stripes with non-empty body gene lists.
     3. Join RNA-seq — load_rna_for_se() → join log2FC, padj to each hub gene.
     Mark DEG status.
     4. Coordinate regulation test — Per SE-hub stripe: compute hub_size,
     n_degs, pct_degs, mean_body_gene_lfc, direction_concordance (sign match
     between stripe logFC and body gene lfc). 1,000-permutation test shuffling
     gene-stripe assignments.
     5. SE-hub vs non-SE-hub comparison — Wilcoxon: pct_degs in SE-hub vs
     non-SE-hub stripes. Test whether SE-hub stripes have stronger DEG
     enrichment.
     6. Multi-hub genes — Genes appearing in >=2 SE-hub stripes. Test
     consistency of regulation across hubs.
     7. Figures — (i) Hub size histogram (SE-hub vs all). (ii) DEG enrichment
     violin (direction x SE-hub status). (iii) Coordination scatter (mean body
     gene lfc vs stripe logFC, per hub). (iv) Concordance bar. (v) Multi-hub
     gene dot plot (top 20 genes by hub count).

     Input files

     - stripes/stripenn/outputs/250402/250402_stripes_allsig.bedpe (late)
     - stripes/stripenn/outputs/250831/250831_stripes_{allsig,concordant}.bedpe
     (early — both)
     - peaks/Superenhancers_P60.bed, peaks/Superenhancers_encode.bed
     - tads/adult_timepoint_rna-seq-BAP1_WT_KO_v2_Results.xlsx (late)
     - tads/young_timepoint_rna-seq-Bap1Math1paired_ctrl_mut_Results.xlsx
     (early)

     ---
     Implementation Order

     1. se_utils.R first (all scripts depend on it)
     2. se_stripe_overlap.R second (simplest — pure overlap, no gene matching)
     3. se_deg_proximity.R third (adds gene matching, proximity windows, K27ac
     subclass)
     4. se_hub_classification.R last (most complex — coordination test,
     permutations)

     ---
     Verification

     For each script, after implementation:

     1. Run on late timepoint — Rscript loops/scripts/<script>.R --timepoint 
     late
     2. Check outputs exist — TSV tables, multi-format figures, statistics files
     3. Spot-check table dimensions — e.g., gene_se_proximity.tsv should have
     rows proportional to DEG count x average SE density
     4. Verify statistics — p-values, odds ratios, Spearman rhos in statistics
     files should be non-degenerate
     5. Run on early timepoint — expect fewer results (fewer stripes, different
     DEG set)
     6. Run --timepoint both — confirm both outputs generated

     No unit tests needed (this is a single-run analysis pipeline), but each
     script should stop() with a clear message on missing inputs.
