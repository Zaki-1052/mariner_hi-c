     Plan: Loop Anchor CTCF Motif Analysis (TODO #2)

     Context

     The CTEA meeting and Dixon meeting (slide 13) raised the question: "Are 
     changes happening at the actual CTCF motif?" Current loop anchors are 10 kb
      Hi-C resolution bins — too coarse for motif-level insight. The 19 bp CTCF
     DNA motifs within those anchors may tell a different chromatin story than
     the broad 10 kb window. This script implements TODO item #2 (sections 2a,
     2b, 2c) as a standalone analysis that reads the already-computed annotated
     loops and refines them at motif resolution.

     The existing annotate_loops_extended.R is not modified — a new
     self-contained script is created following the SE analysis code style.

     ---
     Key Design Decisions

     Self-contained helpers over sourcing annotate_loops_extended.R: The
     existing script uses relative paths from peaks/ and would require
     refactoring to source from project root. Faithful copies of the
     classification logic avoid coupling.

     ±500 bp motif window: The CTCF footprint is 19 bp; ChIP-seq peaks are ~230
     bp; flanking nucleosome histone marks extend ~150-300 bp from the motif. A
     ±500 bp window (1 kb total) captures the motif + co-localizing ChIP signal
     without overlapping adjacent motifs in most cases. Sensitivity analysis at
     ±250 bp and ±1000 bp validates this choice.

     Multiple motifs per anchor: Each motif gets its own window and annotation.
     Per-anchor consensus uses the highest-priority type (earliest in
     ANCHOR_TYPE_ORDER) across all motif windows — this captures the most
     biologically significant signal (e.g., if one window is Active_Promoter, it
      dominates over a neighboring CTCF_Site window).

     Motif-centered windows always have CTCF motif overlap: By construction,
     every window is built around a motif, so CTCF_motif_overlap = TRUE for all.
      The interesting question is whether a higher-priority histone mark also
     overlaps the window, reclassifying it away from CTCF_Site.

     2b uses pre-computed columns: The anchor{1,2}_CTCF_motif_overlap booleans
     in the TSV are sufficient for the filter — no re-computation needed.

  Key Findings (Late)

  2a — Re-centering on CTCF motifs:
  - 70% of anchors contain a CTCF motif; 38% have exactly 1, 20% have 2, 15%
  have 3+
  - 68% concordance between 10 kb and motif-window classifications — so ~32% of

  - The concordance plot tells the story clearly: CTCF_Site expands dramatically
   at motif resolution (from ~36% to ~55%), absorbing signal from
  Poised_Enhancer, Polycomb, and Active_Promoter. Those histone marks are real
  at 10 kb but the actual motif sits in a mark-free region.
  - CTCF_Site itself is 94% concordant (1454/1551) — the most stable type

  - Only 12.7% of loops lost when requiring ≥1 CTCF anchor
  - The CTCF count plot is striking: gained loops (up) are 65% both-CTCF vs only

   be down (241 vs 128). This supports the structural loop interpretation — BAP1
   mutant gains CTCF-CTCF structural loops while losing enhancer-driven
  regulatory loops.
  - Fisher tests confirm: CTCF_Site-CTCF_Site infinitely enriched in filtered

⏺ Good question — let me unpack that.

  A 10 kb anchor is a Hi-C resolution bin. It can contain multiple regulatory
  elements that are spatially distinct within the bin. The classification
  priority system means histone marks always trump CTCF: if the anchor has
  H3K4me1, it gets called Poised_Enhancer even if it also contains a CTCF motif.

  When you zoom to ±500 bp around the actual CTCF motif, the histone mark often
  isn't there. It's elsewhere in the same 10 kb bin. So the motif window gets
  classified as CTCF_Site because there's no histone signal at that specific
  location.

  Concrete example: a 10 kb anchor has a CTCF motif at position 3 kb and an
  H3K4me1 peak at position 8 kb. At 10 kb, both overlap the anchor →
  "Poised_Enhancer" (H3K4me1 is higher priority than CTCF). At ±500 bp around
  the motif (2.5-3.5 kb), the H3K4me1 peak is 4.5 kb away and outside the window
   → "CTCF_Site."

  The transition matrix confirms this pattern — the biggest reclassifications
  are all [histone type] → CTCF_Site:
  - 333 Poised_Enhancer → CTCF_Site (38% of that type)
  - 211 Polycomb → CTCF_Site (29%)
  - 108 Active_Promoter → CTCF_Site (35%)
  - 90 Active_Enhancer → CTCF_Site (27%)

  The biological interpretation: CTCF and histone marks are adjacent but not 
  co-localized within most anchors. The CTCF motif provides the structural
  anchor for the loop, and the nearby enhancer/promoter/polycomb element
  provides the regulatory function — but they're separate elements that happen
  to fall in the same 10 kb bin.
