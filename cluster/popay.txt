Hi Challana,

It was great meeting with you.

Most of the code I used for analysis of different Hi-C loops is available on GutHub: https://github.com/tpopay/HiC-clustering/tree/main

In particular, the ChromHMM anchor vs span can be found in the grouped_loops_figures.ipynb notebook under "ChromHMM relationship”. This sets all of the files up and calls ChromHMM OverlapEnrichment as a subprocess and then uses my own plotting function to make the figure. You could use this as a guide for running OverlapEnrichment separately if you want, otherwise you could also format your decreased/increased chromatin loops similar to this: https://drive.google.com/file/d/1plXEwM7la_Ck5U0eBXCDIMk_Jh8Wm_Bj/view?usp=drive_link (you would only need to coordinates, i.e. the first 6 columns) and use it as input for most of the pipeline. If you take this latter approach, there are some .yml files on the main GitHub page that can create a conda environment with all of the required packages.

Let me know if you need help with this at all.
Tessa
