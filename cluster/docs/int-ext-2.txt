     Plan: Comprehensive Interior/Exterior Asymmetry Analysis

     Context

     The existing oriented-anchor metagene pipeline (scripts 09-10) demonstrated
      that K27me3 is interior-enriched at clust5 gained-loop anchors
     (Ext/Int=0.91, p=0.004) and symmetric at clust6 lost-loop anchors
     (Ext/Int=1.02, p=0.52). The user wants to extend this analysis to
     additional signal types -- H2AK119ub, H3K27ac, compartment PC1 eigenvector,
      and insulation scores -- for both clust5 and clust6 (plus clust6
     short/long subgroups). Since PC1 and insulation must be computed from
     mcools on HPC, the script is designed as an sbatch job for SDSC Expanse.

     Key Design Decisions

     1. Two spatial scales: Histone marks (H2AK119ub, H3K27ac) at +-5kb/binSize
     10bp (anchor-local, matching existing Phase 8). Compartment features (PC1,
     insulation) at +-50kb/binSize 1000bp (domain-scale, since PC1 is 25kb bins
     and insulation is 10kb bins -- +-5kb would give <1 bin per side).
     2. Two separate computeMatrix runs: Can't use bed_pileup() for the
     compartment run because it hardcodes --missingDataAsZero (wrong for PC1
     which has real zeros and negatives) and doesn't support --binSize. Build
     computeMatrix commands directly via subprocess.
     3. Clusters analyzed: clust5, clust6, clust6_short, clust6_long (4 groups).
      Reuse existing oriented anchor BED6 files from deeptools_input/.
     4. PC1 from cooltools: cooltools eigs-cis --bigwig at 25kb resolution with
     H3K27ac phasing track (ensures positive=A compartment). Produces BigWig
     directly (uses bedGraphToBigWig internally, which is in the cluster conda
     env).
     5. Insulation from cooltools: cooltools insulation --bigwig at 10kb
     resolution, 200kb diamond window.
     6. All 6 clusters included: Run computeMatrix on all 6 clusters for
     completeness (the oriented BEDs already exist), but focus visualization on
     the clust5/clust6/subgroups contrast.

     computeMatrix command construction

     Histone run (H2AK119ub + H3K27ac, +-5kb):
     computeMatrix reference-point --referencePoint center \
       --missingDataAsZero \
       -S H2AK119ubCtrl.bw H2AK119ubMut.bw H3K27acCtrl.bw H3K27acMut.bw \
       -R clust5_oriented_anchors.bed clust6_oriented_anchors.bed \
          clust6_short_oriented_anchors.bed clust6_long_oriented_anchors.bed \
       -o {out}/histone_anchors -bl {blacklist} -p {nproc} \
       --outFileNameMatrix {out}/histone_values \
       -b 5000 -a 5000 --sortRegions keep \
       --samplesLabel H2AK119ub_ctrl H2AK119ub_mut H3K27ac_ctrl H3K27ac_mut

     Compartment run (PC1 + insulation, +-50kb, 1kb bins):
     computeMatrix reference-point --referencePoint center \
       -S PC1_ctrl.cis.bw PC1_mut.cis.bw insulation_ctrl.200000.bw
     insulation_mut.200000.bw \
       -R clust5_oriented_anchors.bed clust6_oriented_anchors.bed \
          clust6_short_oriented_anchors.bed clust6_long_oriented_anchors.bed \
       -o {out}/compartment_anchors -bl {blacklist} -p {nproc} \
       --outFileNameMatrix {out}/compartment_values \
       -b 50000 -a 50000 --binSize 1000 --sortRegions keep \
       --samplesLabel PC1_ctrl PC1_mut insulation_ctrl insulation_mut

     No --missingDataAsZero for compartment -- PC1 has real negative values and
     zeros; NaN bins get filtered by the Wilcoxon valid-mask.
