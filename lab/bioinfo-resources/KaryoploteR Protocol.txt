Your BigWig and BED files must be stored in the same folder as your working directory.  If your script is not stored in the work directory, or is just stored in the home directory, make sure your files are also stored in a home directory, or set a wk directory in R and provide a path to your files. a. If a Mac user, type Òshift+command+hÓ and move the file out of the folder it is stored in. 2. You can change file names before plotting, just make sure that they line up. 3. Parameters that can be changed are highlighted in orange: a. at <- autotrack(current.track = 6, total.tracks = 8, r0=0.35, r1=1)b. data=Òfile nameÓc. col = ÒcolorÓd. ymax= ÒnumberÓe. labels =Òlabel namesÓ4. VERY IMPORTANT! YOU MUST RUN THE START OF THE CODE IN ORDER!a. Must plot the genes before you can plot the bigwigs.  Otherwise it will be VERY SLOW.5. Make sure you change the chromosomal coordinates every time you make a plot. 6. Cole generally prefers ymax = Ò100Ó for all tracks. a. Sometimes the plots will look like they are cut off, but they are plotted, setting everything to 100 makes it easier for Cole to adjust in Illustrator later. 7. Set Òtotal.tracksÓ to however many tracks you will be plotting.  For example, 4 bigwigs + 4 bedfiles = 8 total.  8. Set Òcurrent.trackÓ in descending order.  The track on the very top will be track 8, and 1 will be the one closest to the bottom. 9. If you plan on changing the color of the files, edit col="limegreen" with the color you would like to use.  a. For guidance, plot different histone modifications with different colors b. Generally, try to plot in this order: ÒblueÓ, ÒredÓ, ÒgreenÓ, ÒmagentaÓ, ÒorangeÓ although Cole may want different colors later on anyways so it probably doesnÕt matter. c. Can also use hexadecimal values for custom color. 10. We will mostly be plotting with mice, if you are plotting human data, you will need to download the analogous human packages for the labeling and the genome.  Also make sure you change it from Òmm10Ó to Òhg38Ó11. If you have more or less tracks, you can duplicate the same code, and just change the parameters to accommodate the number of samples.  If you donÕt want something to plot, just donÕt run the line of code. Exporting the Plot1. To export the plot, click the export button on RStudioa.
