# TADCompare Results Guide

This document describes the output files generated by the TADCompare differential TAD boundary analysis pipeline.

## Directory Structure

```
results/
├── {timepoint}/           # "late" or "early"
│   ├── tadcompare/        # Step 2: Raw TADCompare output
│   ├── consensus/         # Step 3: Robustness annotations
│   └── final/             # Steps 4-5: Final annotated & filtered results
├── visualizations/
│   └── {timepoint}/       # Step 6: All plots organized by category
└── tracks/                # Optional genome browser tracks
```

---

## Column Definitions (All TSV/BED Files)

### Core TADCompare Columns

| Column | Description |
|--------|-------------|
| `chr` | Chromosome (chr1-chr19, autosomes only) |
| `Boundary` | Genomic coordinate of the TAD boundary (bp) |
| `Gap_Score` | Differential boundary score (Z-score). Positive = stronger in Control, Negative = stronger in Mutant |
| `TAD_Score1` | Boundary strength score in Control (Matrix 1) |
| `TAD_Score2` | Boundary strength score in Mutant (Matrix 2) |
| `Differential` | Classification: "Differential", "Non-Differential", or "Shifted" |
| `Enriched_In` | Which condition has stronger boundary signal: "Matrix 1" (Control) or "Matrix 2" (Mutant) |
| `Type` | Boundary change type (see Boundary Types below) |

### Robustness Columns (added in Step 3)

| Column | Description |
|--------|-------------|
| `robust_in_ctrl` | TRUE/FALSE - boundary detected in Control replicate consensus |
| `robust_in_mut` | TRUE/FALSE - boundary detected in Mutant replicate consensus |
| `robustness` | Combined robustness: "Both", "Control_only", "Mutant_only", or "Neither" |

### Shift Distance Columns (added in Step 4)

| Column | Description |
|--------|-------------|
| `shift_distance` | Distance to nearest opposite-enriched boundary (bp). Only populated for Type="Shifted" |
| `shift_distance_kb` | Same as above, in kilobases |

### BED-Specific Columns

BED files include standard BED6 columns plus additional metadata:

| Column | Description |
|--------|-------------|
| `start` | Boundary coordinate (same as `Boundary`) |
| `end` | Boundary + resolution (10kb) |
| `name` | Combined Type_Enriched_In label |
| `score` | Scaled |Gap_Score| × 100, capped at 1000 (for visualization intensity) |
| `strand` | Always "." (not applicable) |

## Boundary Types

TADCompare classifies differential boundaries into the following types:

| Type | Description |
|------|-------------|
| `Non-Differential` | Boundary present in both conditions with similar strength |
| `Strength Change` | Boundary exists in both conditions but with different strengths |
| `Shifted` | Boundary position has moved between conditions |
| `Split` | One TAD in Control has split into multiple TADs in Mutant |
| `Merge` | Multiple TADs in Control have merged into one TAD in Mutant |
| `Complex` | Combination of changes that don't fit other categories |

## File Descriptions by Directory

### `tadcompare/` - Step 2 Output

Raw output from TADCompare differential analysis on merged matrices.

| File | Description |
|------|-------------|
| `tadcompare_all_boundaries.tsv` | All detected boundaries with differential classification |
| `tadcompare_differential_only.tsv` | Subset containing only differential boundaries (excludes Non-Differential) |
| `tadcompare_boundaries.bed` | All boundaries in BED format for genome browsers |
| `tadcompare_differential.bed` | Differential boundaries only in BED format |
| `tadcompare_summary.txt` | Summary statistics from TADCompare analysis |

**tadcompare_summary.txt contents:**
- Analysis metadata (date, resolution, chromosomes)
- Differential status breakdown (counts and percentages)
- Boundary type distribution
- Enrichment direction summary (Control vs Mutant)
- Per-chromosome differential boundary counts

---

### `consensus/` - Step 3 Output

Robustness assessment using ConsensusTADs on individual replicates.

| File | Description |
|------|-------------|
| `tadcompare_with_robustness.tsv` | Full TADCompare results with robustness columns added |
| `consensus_control.tsv` | ConsensusTADs output for Control replicates |
| `consensus_mutant.tsv` | ConsensusTADs output for Mutant replicates |
| `high_confidence_differential.tsv` | Differential boundaries where robustness != "Neither" |
| `high_confidence_differential.bed` | Same as above in BED format |
| `consensus_summary.txt` | Summary of robustness assessment |

**consensus_control.tsv / consensus_mutant.tsv columns:**

| Column | Description |
|--------|-------------|
| `Coordinate` | Boundary position (bp) |
| `Sample 1-3` | TAD scores from each replicate |
| `Consensus_Score` | Median score across replicates |
| `chr` | Chromosome |
| `condition` | "control" or "mutant" |
| `n_replicates` | Number of replicates (always 3) |

**consensus_summary.txt contents:**
- Consensus boundary counts per condition
- Robustness distribution (Both/Control_only/Mutant_only/Neither)
- Robustness breakdown by differential status
- High-confidence differential boundary count

---

### `final/` - Steps 4-5 Output

Final annotated results with shift distances and blacklist filtering.

| File | Description |
|------|-------------|
| `tadcompare_final_annotated.tsv` | Full results with robustness + shift distance columns |
| `tadcompare_final_filtered.tsv` | Same as above, with blacklisted regions removed |
| `tadcompare_final.bed` | All boundaries in BED format (13 columns) |
| `differential_boundaries_final.bed` | Differential boundaries only in BED format |
| `shifted_boundaries.bed` | Shifted boundaries only in BED format |
| `blacklist_removed_boundaries.tsv` | Boundaries that were removed by blacklist filtering |
| `analysis_summary.txt` | Shift distance statistics summary |
| `blacklist_filter_summary.txt` | Blacklist filtering statistics |

**analysis_summary.txt contents:**
- Total boundary count
- Differential and shifted boundary counts
- Shift distance statistics (median, mean)

**blacklist_filter_summary.txt contents:**
- Blacklist sources and region counts
- Boundaries removed (count and percentage)
- Differential boundaries removed
- High-confidence boundaries removed
- Chromosomes with most removed boundaries
- Gap score distribution of removed boundaries

## Interpreting Key Metrics

### Gap Score
- **Positive values**: Boundary is stronger in Control
- **Negative values**: Boundary is stronger in Mutant
- **Magnitude**: Larger absolute values indicate greater differential strength
- Values are Z-scores; |Gap_Score| > 2 indicates significance

### TAD Scores
- Higher values indicate stronger boundary signal
- Compare TAD_Score1 (Control) vs TAD_Score2 (Mutant) to see direction of change

### Robustness
- **Both**: Boundary detected in replicate consensus for both conditions (highest confidence)
- **Control_only / Mutant_only**: Detected in one condition's replicates only
- **Neither**: Not consistently detected across replicates (lower confidence)

### Shift Distance
- Only calculated for Type="Shifted" boundaries
- Represents genomic distance to the nearest boundary enriched in the opposite condition
- Small values (< 10kb) indicate minor repositioning; larger values indicate more substantial shifts

## File Format Notes

### TSV Files
- Tab-separated values with header row
- Can be opened in Excel, R, Python pandas, etc.
- NA values indicate missing data (e.g., shift_distance for non-shifted boundaries)

### BED Files
- Tab-separated, no header row (standard BED format)
- Compatible with genome browsers (IGV, UCSC, Juicebox)
- Extended BED format with additional columns beyond standard BED6

### Blacklist Files Used
- Lab-specific blacklist: `250123blacklist.bed`
- ENCODE mm10 blacklist: `mm10-blacklist.v2.bed`
- Combined and merged before filtering
