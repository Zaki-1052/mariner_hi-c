     Proposed Visualizations (9 figures)

     1. Cumulative Distribution Function (CDF) by Direction

     Purpose: Visually demonstrate that lost loops (down_in_mutant) are
     systematically longer than gained loops (up_in_mutant)
     - X-axis: Loop distance (log10 scale)
     - Y-axis: Cumulative proportion
     - Two curves: Up (gained) vs Down (lost)
     - Kolmogorov-Smirnov test p-value annotation
     - Key insight: If the "down" curve is shifted right, confirms longer
     loops are preferentially lost

     2. Distance Category Stacked/Grouped Bar Chart

     Purpose: Quantify the asymmetry in gains vs losses across distance bins
     - X-axis: Distance categories (<100kb, 100-500kb, 500kb-1Mb, >1Mb)
     - Y-axis: Count or percentage
     - Grouped bars: Up vs Down in each category
     - Calculate and annotate fold-enrichment ratios
     - Key insight: Show that >1Mb category is enriched for "down" while
     <100kb is enriched for "up"

     3. Density Plot with Median Annotations

     Purpose: Show the distributional shift clearly
     - Overlaid density curves (Up = blue, Down = red)
     - Vertical dashed lines at medians
     - Shaded difference region
     - Wilcoxon test p-value
     - Key insight: Visual separation of density peaks

     4. LogFC vs Distance Scatter with Trend

     Purpose: Show correlation between effect magnitude and loop distance
     - X-axis: Loop distance (log10)
     - Y-axis: logFC
     - Points colored by significance (FDR < 0.05)
     - LOESS trend line with confidence interval
     - Spearman correlation annotation
     - Key insight: Negative correlation = longer loops more likely to
     decrease

     5. Distance-Stratified Volcano Plots (Faceted)

     Purpose: Show differential patterns change with loop distance
     - 4-panel facet by distance_category
     - Standard volcano (logFC vs -log10 FDR)
     - Annotate significant counts per panel
     - Key insight: Different effect patterns at different distance scales

     6. Loop Type × Distance Heatmap

     Purpose: Identify which biological loop types are most affected at each
      distance
     - Rows: Loop types (Promoter-Enhancer, Enhancer-Enhancer, etc.)
     - Columns: Distance categories
     - Fill: Net change (# up - # down) or log2 ratio
     - Key insight: Specific loop types may show distance-dependent effects

     Purpose: Show if long lost loops are enriched at specific chromatin
     states
     - Panel A: Stacked bar showing H3K27ac/H3K4me1 anchor overlap by
     distance bin & direction
     - Panel B: Mosaic plot of anchor type
     (Promoter/Active_Enhancer/Poised_Enhancer/Other) vs distance
     - Panel C: Chi-square test results for association between chromatin
     state and distance
     - Key insight: Determine if developmental (poised) vs active enhancer
     loops have different distance profiles
