     Context & Background

     Data Understanding

     - Early timepoint: 166 total differential loops (very small dataset)
       - 73 up_in_mutant (44.2%)
       - 92 down_in_mutant (55.8%)
     - "Other" category: Anchors with NO ChIP-seq marks (H3K27ac, H3K27me3,
     H3K4me1, H3K4me3)
     - "Up" loops: Positive logFC = increased contact strength in BAP1-KO
     mutant
     - Critical caveat: CTCF ChIP-seq data is only available for late
     timepoint, NOT early

     CRITICAL FINDING: CTCF Data Impact on "Other" Classification

     Comparison of anchor type distributions:

     ┌────────────────────┬────────────────────┬──────────────────┐
     │    Anchor Type     │  Early (no CTCF)   │ Late (with CTCF) │
     ├────────────────────┼────────────────────┼──────────────────┤
     │ CTCF_Site          │ 0% (not available) │ 24.0%            │
     ├────────────────────┼────────────────────┼──────────────────┤
     │ Other              │ 36.5%              │ 9.3%             │
     ├────────────────────┼────────────────────┼──────────────────┤
     │ Repressed_Promoter │ 35.8%              │ 9.6%             │
     └────────────────────┴────────────────────┴──────────────────┘
     Key insight: The high "Other" proportion in early (~37%) vs late (~9%)
     is largely explained by missing CTCF data. In late timepoint, ~24% of
     anchors are CTCF_Site. If early timepoint had CTCF data, the "Other"
     category would likely drop to ~10-13% (similar to late).

     Implication: ~60-70% of early "Other" anchors may actually be
     CTCF-mediated structural elements.

     Biological Significance of "Other" in Early Timepoint

     Since CTCF data is unavailable for early timepoint:
     - Early "Other" anchors could be:
       a. CTCF-mediated structural sites (LIKELY - estimated ~60-70%)
       b. Truly unmarked genomic regions (less common)
       c. Regions with marks below detection threshold
     - This is a key limitation to communicate to the PI

     - Contains 166 loops with full annotation columns

     1. Read early timepoint characterized loops
     2. Filter for direction == "up_in_mutant" (73 loops)
     3. Filter for loops where at least one anchor is "Other":
       - anchor1_type_extended == "Other" OR

     4. Add category breakdown:
       - both_other: Both anchors are "Other" (Other-Other loops)
       - single_other: Only one anchor is "Other" (e.g., Promoter-Other,
     Polycomb-Other)

     Step 2: Rank by Significance

     Sort by multiple criteria (for comprehensive view):
     - Primary: FDR (ascending - most significant first)
     - Secondary: |logFC| (descending - strongest effect)
     - Category: strong_differential > moderate_differential >
     weak_differential

     Step 3: Annotate with Gene Information

     For each anchor, retrieve:
     - Nearest gene name(s)
     - Distance to nearest TSS
     - Gene function (if available via biomaRt or org.Mm.eg.db)

     Step 4: Generate Output Tables

     Table 1: Most Significant "Other" Up Loops (Top 20)

     Columns:
     - Genomic coordinates (chr:start-end for both anchors)
     - logFC, FDR, category
     - Anchor1 type, Anchor2 type
     - Nearest genes (both anchors)
     - Loop distance

     Table 2: Summary Statistics

     - Distribution of "Other" combinations (Other-Other,
     Active_Promoter-Other, etc.)
     - Comparison to late timepoint

     Step 5: Validation Check
