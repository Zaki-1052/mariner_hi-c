Volcano Plot

This plot displays methylation differences between conditions (x-axis) against statistical significance (-log10 q-value, y-axis). Points further from zero on the x-axis represent larger methylation differences, with negative values indicating hypomethylation and positive values indicating hypermethylation.

P-value Distribution

This histogram shows the distribution of p-values across all analyzed regions. A uniform distribution suggests properly controlled statistical testing, while a peak near zero indicates the presence of statistically significant differences between conditions.
