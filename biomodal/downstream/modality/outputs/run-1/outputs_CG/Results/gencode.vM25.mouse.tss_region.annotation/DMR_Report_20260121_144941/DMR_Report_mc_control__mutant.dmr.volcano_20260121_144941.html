Insufficient Sample Size Warning

All p-values in this analysis are 1.0, indicating insufficient sample sizes for statistical modeling.

This occurs when one or more experimental groups have too few samples relative to the number of covariates being tested. Specifically:

  • Minimum requirement: Each group needs more than (1 + number of optional covariates) samples
  • Example: With no optional covariates, each group needs at least 2 samples
  • Example: With 1 optional covariate (e.g., age), each group needs at least 3 samples

What this means for your results:

  • P-values are not meaningful - all set to 1.0 as a conservative measure
  • Statistical significance cannot be determined - no reliable hypothesis testing possible
  • Effect sizes (methylation differences) are still valid and can provide biological insights

Recommended actions:

  1. Verify your experimental design and sample groupings
  2. Consider collecting additional samples if possible
  3. Focus interpretation on effect sizes rather than statistical significance
  4. Consider reducing the number of covariates if appropriate for your study
