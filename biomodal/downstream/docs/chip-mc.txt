     Biomodal DUET evoC Visualization Plan

     Overview

     Create a comprehensive R visualization script for the biomodal
     differential methylation (5mC and 5hmC) analysis between BAP1-KO mutant
      and wildtype control mice.

     Key Findings to Visualize

     - Primary affected regions: Gene bodies (NOT promoters or CpG islands)
     - Coordinated pattern: 5mC increase + 5hmC decrease at same loci
     - Top genes: Syt1 (highest!), Zbtb20, Cntnap2, Trpm3
     - Significant DMRs: 4,188 mC + 4,897 hmC gene body DMRs (CG context)
     - Non-CpG methylation: No significant changes in CHG/CHH contexts

     ol__mutant_20260121_172049.bed

     DMR BED File Format (14 columns)

     - Chromosome, Start, End, num_contexts, mean_coverage
     - mean_mod_group_1 (control), mean_mod_group_2 (mutant)
     - mod_fold_change, mod_difference, test_statistic
     - dmr_pvalue, dmr_qvalue, Annotation, Name (gene)

      by sample

     specificity

     (within-group 0.76-0.79)
     2. 5hmC correlation heatmap - 4x4 sample correlation matrix

     3. PCA plots - PC1 vs PC2 for mC and hmC, colored by condition

     4. Label key genes: Syt1, Zbtb20, Cntnap2, Trpm3

      279 +classify_chromatin_state <- function(overlaps,

      281 +  chromatin_state <- rep("Other", n)

      285 +  h3k27me3 <- overlaps$H3K27me3_overlap                       
      286 +  h3k4me1 <- overlaps$H3K4me1_overlap                         
      287 +  h3k4me3 <- overlaps$H3K4me3_overlap                         
      288 +  bivalent <- overlaps$Bivalent_overlap                       
      289 +                                                              
      290 +  # 1. Active_Promoter: H3K4me3+ AND NOT H3K27me3 AND <=2kb

      292 +    !is.na(distance_to_tss) & distance_to_tss <=

      294 +

      298 +    !is.na(distance_to_tss) & distance_to_tss <=

      302 +  is_bivalent <- !is_active_promoter & !is_repressed_promoter

      303 +  chromatin_state[is_bivalent] <- "Bivalent_Promoter"         
      304 +                                                              
      305 +  # 4. Polycomb: H3K27me3+ AND >2kb from TSS                  
      306 +  is_polycomb <- !is_active_promoter & !is_repressed_promoter 
          + & !is_bivalent &                                             
      307 +    h3k27me3 & (is.na(distance_to_tss) | distance_to_tss >    
          +tss_threshold)                                                
      308 +  chromatin_state[is_polycomb] <- "Polycomb"                  
      309 +                                                              
      310 +  # 5. Active_Enhancer: H3K27ac+ AND >2kb from TSS            
      311 +  is_active_enhancer <- !is_active_promoter &
